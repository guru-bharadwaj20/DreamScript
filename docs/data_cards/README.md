One card per dataset, filled in before the dataset is used for training. `TEMPLATE.md` is the
form; `dreamscript_chaos.md` is a worked example for the corpus collected by this project.

A card is complete when every field has a value — "unknown" counts, blank does not — and the
license row states explicitly whether the raw files may be redistributed. Phase 1.1.6 closes
out the license audit across all five public datasets.
