# Collection Brief — Flowchart

**Target: 60 sketches** across 10 scenarios and 8 scribes.

Generated by `scripts/make_collection_sheets.py` from `src/ingest/collection.py`. Do not edit by hand.

## How to draw these

Draw the way you would on a whiteboard in a meeting: do not straighten arrows, do not redraw a box because it came out crooked. **If an arrow does not quite touch a box, leave it.** That gap is the single hardest thing this project has to solve (Phase 10.1.4), and clean drawings give it nothing to learn from.

## Scenarios

| # | Scenario | What to draw | Must contain |
| :---: | :--- | :--- | :--- |
| 1 | **Login validation** (`login_check`) | Read username and password, check them, branch to success or retry. | start, decision, loop back, end |
| 2 | **Age gate** (`age_gate`) | Ask for age; if 18 or over allow entry, otherwise refuse. | decision on a comparison, two branches |
| 3 | **Grade calculator** (`grade_calc`) | Take a mark and print A/B/C/F using a chain of comparisons. | three or more decisions, one end |
| 4 | **ATM withdrawal** (`atm_withdraw`) | Card, PIN, balance check, dispense or decline, with a PIN retry loop. | loop, nested decision, io node |
| 5 | **Bubble sort** (`bubble_sort`) | Two nested loops with a swap in the middle. | nested loop, back edge |
| 6 | **Order processing** (`order_pipeline`) | Receive order, check stock, take payment, ship or refund. | four or more processes, two terminals |
| 7 | **FizzBuzz** (`fizzbuzz`) | Loop 1..n with divisibility decisions and three print branches. | loop, three-way branch |
| 8 | **Download with retry** (`file_retry`) | Attempt a download, retry up to three times, then fail. | counter, loop, failure terminal |
| 9 | **Triangle classifier** (`triangle_type`) | Given three sides, decide equilateral, isosceles or scalene. | chained decisions |
| 10 | **Password reset** (`password_reset`) | Request reset, send email, verify token, set new password. | io node, decision, linear chain |
