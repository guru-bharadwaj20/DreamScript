# Collection Brief — Wireframe

**Target: 60 sketches** across 10 scenarios and 8 scribes.

Generated by `scripts/make_collection_sheets.py` from `src/ingest/collection.py`. Do not edit by hand.

## How to draw these

Sketch the layout only — boxes, lines for text, a cross for an image. Do not write real copy; a squiggle standing in for a line of text is what a real wireframe looks like. Nesting matters more than neatness: a card inside a grid inside a page.

## Scenarios

| # | Scenario | What to draw | Must contain |
| :---: | :--- | :--- | :--- |
| 1 | **Login screen** (`login_form`) | Title, email field, password field, submit button, forgot-password link. | two inputs, one button, one link |
| 2 | **Sign-up screen** (`signup_form`) | Four fields, a checkbox for terms, and a primary button. | four inputs, checkbox |
| 3 | **Analytics dashboard** (`dashboard`) | Header, sidebar nav, four stat tiles, one chart area. | sidebar, grid of tiles, chart placeholder |
| 4 | **Product listing** (`product_list`) | Search bar, filter column, grid of product cards with images. | grid, image placeholders |
| 5 | **User profile** (`profile_page`) | Avatar, name, bio block, tabbed section, edit button. | avatar circle, tabs |
| 6 | **Settings** (`settings_page`) | List of labelled rows with toggles, grouped into sections. | repeated rows, toggles |
| 7 | **Checkout** (`checkout`) | Order summary on the right, address form on the left, pay button. | two columns, form |
| 8 | **Chat window** (`chat_ui`) | Conversation list, message bubbles, input box with a send button. | list, bubbles, input row |
| 9 | **Mobile feed** (`mobile_feed`) | Narrow frame, top bar, scrolling cards, bottom tab bar. | bottom nav, cards |
| 10 | **Admin table** (`data_table`) | Toolbar, table with five columns and a pagination row. | table grid, pagination |
