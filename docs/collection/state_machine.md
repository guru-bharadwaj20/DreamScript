# Collection Brief — State Machine

**Target: 50 sketches** across 10 scenarios and 8 scribes.

Generated by `scripts/make_collection_sheets.py` from `src/ingest/collection.py`. Do not edit by hand.

## How to draw these

Circles for states, double circle for accepting. Label every transition, even if the label is one letter. Include at least one self-loop where the scenario allows — self-loops are the feature that separates state machines from flowcharts in the Phase 4.1.7 connectivity features.

## Scenarios

| # | Scenario | What to draw | Must contain |
| :---: | :--- | :--- | :--- |
| 1 | **Traffic light** (`traffic_light`) | Red, amber, green cycling on a timer. | cycle, three states |
| 2 | **Vending machine** (`vending_machine`) | Idle, coin inserted, selection made, dispensing, refund. | self-loop on coin insert, accepting state |
| 3 | **TCP connection** (`tcp_handshake`) | CLOSED, LISTEN, SYN_RCVD, ESTABLISHED, FIN_WAIT, CLOSED. | labelled transitions, return to start |
| 4 | **Elevator** (`elevator`) | Idle, moving up, moving down, doors open, with request transitions. | bidirectional transitions |
| 5 | **Turnstile** (`turnstile`) | Locked and unlocked, with coin and push transitions. | two states, two self-loops |
| 6 | **Order lifecycle** (`order_state`) | Placed, paid, shipped, delivered, cancelled. | terminal state, branch to cancelled |
| 7 | **Media player** (`media_player`) | Stopped, playing, paused, with play/pause/stop transitions. | three states, cycle |
| 8 | **DFA for (ab)+** (`regex_dfa`) | Start, q1, accepting state, with a and b transitions and a dead state. | double-circle accepting state, dead state |
| 9 | **Smart lock** (`door_lock`) | Locked, unlocking, unlocked, auto-relock after timeout. | timeout transition |
| 10 | **Game loop** (`game_states`) | Menu, playing, paused, game over, back to menu. | return edge to start |
