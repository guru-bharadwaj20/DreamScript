## Where the code comes from

| basis | pairs | what it means |
| :--- | ---: | :--- |
| `source` | 484 | the code **is** the ground truth. Sketch2Code's sketches were drawn from these very HTML pages, so the pairing is exact and nothing was generated |
| `emitted` | 993 | deterministically transcribed from ground-truth structure - one function per drawn step, control flow exactly the drawn arrows |

**An emitted target is not the program a person would have written.** It does not name
variables well, infer business logic, or restructure a cyclic flowchart into nested
`if`s that were never drawn. It is a faithful transcription, which is what makes it
usable as a reference; Phase 12.4's hand-written subset is what raises the ceiling.

## Proof that the code runs

| check | result |
| :--- | :--- |
| Python targets compiled | 993 / 993 |
| Python targets executed | 993 / 993 |
| HTML targets parsed | 484 / 484 |

Executed, not merely compiled: each flowchart program is walked from its start event
and each automaton is run on real input symbols. A generated file that only parses
proves the emitter produced Python; one that runs proves it produced the diagram.

### The gap that matters

| Diagram type | Pairs | Consequence |
| :--- | ---: | :--- |
| flowchart | 693 | covered |
| state_machine | 300 | covered |
| wireframe | 484 | covered |
| er_diagram | 0 | **none.** The ER images are photographed UML class diagrams with no published annotation, so there is no structure to emit SQL from. Phase 12 cannot be evaluated on SQL generation until these are labelled by hand |
| circuit | 0 | **none.** CGHD ships images without the component/wire annotation this extract contains, so there is no netlist to emit. Same consequence as ER |

Two of the five diagram types have **zero** target pairs. That is not a shortfall
against the 260 the plan asks for - it is passed several times over by the other three -
but it does mean any Phase 14 claim about SQL or netlist generation would rest on
nothing. The labelling pipeline in 2.2.1 is how that gets fixed.
